# Catálogo de Especies Vegetales - JavaFX y SQL  

## Descripción del Proyecto  
Este sistema, desarrollado con JavaFX y SQL, facilita la visualización y administración de un catálogo de plantas. Los usuarios pueden explorar, buscar y consultar información detallada sobre diversas especies vegetales.  

## Características Principales  
- Interfaz gráfica interactiva basada en JavaFX.  
- Base de datos SQL para almacenar la información de las plantas.  
- Presentación visual con imágenes y descripciones detalladas.  
- Funcionalidad de búsqueda y filtrado de especies en la base de datos.  

## Tecnologías Utilizadas  
- **JavaFX** para la creación de la interfaz de usuario.  
- **SQL** para la gestión y almacenamiento de datos.  

## Instalación y Configuración  

### Requisitos Previos  
- Contar con **JDK 22** o una versión superior instalada.  
- Tener el **SDK de JavaFX** configurado en el entorno de desarrollo.  
- Disponer de **MySQL** instalado.  
- Asegurar la instalación del **conector JDBC** para MySQL.  

## Propósito del Proyecto  
El objetivo principal de esta aplicación es ofrecer una herramienta eficiente para la gestión y exploración de un catálogo de plantas. A través de una interfaz amigable, los usuarios pueden descubrir información clave sobre diferentes especies, incluyendo nombre, descripción, imágenes y características adicionales.
