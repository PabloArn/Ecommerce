# Pantallas del Proyecto - Catálogo de Especies Vegetales

Este documento describe las principales pantallas de la aplicación desarrollada en JavaFX para la gestión y visualización de un catálogo de plantas.

## 1. Pantalla de Inicio
- Presenta el título de la aplicación y una imagen destacada.
- Contiene botones de navegación hacia las secciones principales.

## 2. Pantalla de Exploración de Plantas
- Muestra una lista de especies de plantas disponibles en la base de datos.
- Permite visualizar las plantas con una imagen miniatura, nombre y categoría.
- Contiene un campo de búsqueda y opciones de filtrado.

## 3. Pantalla de Detalles de la Planta
- Presenta información detallada sobre una especie seleccionada.
- Incluye el nombre, descripción, imagen ampliada y características adicionales.
- Botón para regresar a la pantalla de exploración.

## 4. Pantalla de Gestión de Plantas
- Accesible solo para usuarios con permisos de administración.
- Permite agregar, editar y eliminar registros de plantas.
- Formulario con campos para ingresar nombre, descripción, imagen y categoría.

## 5. Pantalla de Inicio de Sesión
- Formulario para que los usuarios ingresen sus credenciales.
- Validación de acceso y redirección según el rol del usuario.

## 6. Pantalla de Configuración
- Opciones para ajustar preferencias de la aplicación.
- Permite cambiar el tema visual y administrar la conexión con la base de datos.

## 7. Pantalla de Reportes
- Genera informes sobre las plantas registradas en la base de datos.
- Opción para exportar reportes en formatos como PDF o Excel.

Estas pantallas proporcionan una experiencia de usuario intuitiva y organizada, facilitando la consulta y gestión del catálogo de especies vegetales.
